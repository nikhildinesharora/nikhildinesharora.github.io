# Nikhil Arora - Systems Under Stress

An evidence-led software and machine learning systems portfolio.

**Live site:** [nikhildinesharora.github.io](https://nikhildinesharora.github.io/)

## Stack

- React
- TypeScript
- Vite
- Custom SVG interaction and CSS motion
- Lucide icons

The site intentionally avoids premade animated backgrounds and scroll hijacking. The central
interaction is based on the actual architecture of the distributed-training project, while project
claims and metrics are drawn from repository documentation and reports.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Pushes to `main` are automatically built and deployed through GitHub Actions.
